# Test structures

XYZ files in Ångström. Most top-level structures are copies of test inputs of the Grimme-lab
programs (LGPL-3.0-or-later, as their repositories are; the files carry no header of their
own), and several of those trace back to public benchmark sets. The rest were built by hand or
by scripts in this repository. No structure comes from an unpublished research project.
